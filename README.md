# 🩺 Disease Prediction Using Machine Learning

> An end-to-end Machine Learning project that predicts diseases using patient health data. This project covers the complete ML lifecycle—from data loading and exploratory analysis to model training, evaluation, and deployment-ready model serialization.
![Banner](https://github.com/rohannn16/disease-prediction-model/blob/main/images/disease_prediction_banner.png)


---

## 📌 Project Overview

This project aims to build a disease prediction system using Machine Learning techniques to assist in identifying diseases based on patient health indicators and lifestyle-related factors.

The workflow follows industry-standard ML practices, transforming raw healthcare data into a reliable and deployment-ready predictive model.

---

## 🚀 Project Workflow

```
Load Data
   ↓
Data Cleaning & Validation
   ↓
Exploratory Data Analysis (EDA)
   ↓
Feature Engineering & Selection
   ↓
Data Preprocessing
   ↓
Train-Test Split
   ↓
Model Training
   ↓
Hyperparameter Tuning
   ↓
Model Evaluation
   ↓
Model Serialization
   ↓
Deployment Ready
```

## 🔍 Key Features

* Data Loading and Initial Inspection
* Data Cleaning and Validation
* Exploratory Data Analysis (EDA)
* Correlation Analysis
* Feature Engineering and Feature Selection
* Data Preprocessing Pipelines
* Feature Encoding and Scaling
* Stratified Train-Test Split
* Multiple Model Training and Comparison
* Hyperparameter Tuning using GridSearchCV
* Detailed Performance Evaluation
* Classification Reports and Confusion Matrix
* Precision–Recall Analysis
* Model Serialization using Joblib
* Deployment-Ready ML Pipeline

---

## 🤖 Machine Learning Models Used

* Logistic Regression
* Support Vector Machine (SVM)

After evaluating multiple models, **Support Vector Machine (SVM)** was selected as the final model due to its superior performance.
